Project title:Triva 
Project description:The ai agent Triva which stands for technical responsive interface virtual assistant    is being developed to  fulfill the users needs with the resources that the user provides.Multitasking has become a tool required in a vast amount of companies which is where trivia comes in   .Contrary to other chat bots such as chat gpt, claude or grok that  search the world wide web triva will be a software that helps its user  maintain a stable and organized workspace   .Upon completion this ai agent  will allow the users to upload  files stored locally and possibly on the cloud to be used for a question a user may have such as finding a specific file or asking a question about a specific file that no matter the date . Triva will be programmed  to process the users  request and look through a file or folder to fully answer the question you ask based off the information process  and break down  each query into sub task  to give the user the best answers to  there question .

 Html ,css , and javascript will be utilized   for the front end development  to  develop, shape and enhance  the functionality and user interface  of  the program . In addition to python for the  back end development  which will  help  make  ai    operate and respond at a reasonable speed making the evidence base systems answers  more accurate and beneficial to its users .This agent is evidence based so that the user is not misled or thrown on a different path because there will be no suggestions , opinions only knowledge that is already known by its user . Triva can be used to study ,  count files , find a file, summarize a file or folder  and etc. When the user sends a file and question the ai accepts it , processes it and then gives an answer to help the user . Triva accepts large and small files or folders when asking  it to handle a large  volume of data ai it will break down the users questions into sub task to ultimately solve the problem or answer the users query  but when handling a small amount the answer will typically be straight forward .



Project Language used : Html , css , javascript , python

ask a question about the file such as file name , where a specific file is or something specific that you may have forgot and may need the ai to refreshen you about
